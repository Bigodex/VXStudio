# Pack — Tema Amber Minimal + Header com ícones + Hero com movimento

## Alterações incluídas

- Aplicação do tema Amber Minimal nos tokens globais de `app/globals.css`.
- Ajuste de tema claro e escuro com base nos tokens do tweakcn.
- Header com ícones em cada item de navegação.
- Hover no header com barra animada dinâmica usando `w-full`, cobrindo ícone + texto sem largura fixa.
- Hero com intro visual, parallax leve no mockup, scan suave, linha de foco, brilho e cards internos em cascata.
- Regras de desenvolvimento em Markdown para evitar alterações que quebrem o projeto.

## Cuidados

- Não foi criada área logada, dashboard, SaaS, carrinho ou assinatura.
- As animações novas respeitam `prefers-reduced-motion`.
- O pacote altera apenas arquivos necessários para design, experiência e documentação.
